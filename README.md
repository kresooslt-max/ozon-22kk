# StartAuto — Ozon Card Manager (prototype)

Это первая версия интерфейса будущей внутренней панели StartAuto.

## Что уже есть

- Главная панель с KPI, продажами и задачами.
- Каталог товаров с поиском и фильтром.
- Редактор карточки: название, OEM, тип, описание, хэштеги.
- Проверка карточки: OEM / применяемость / фото / источники.
- Аналитика продаж.
- Управление фото и порядок изображений.
- Раздел исследования: RIV → OEM → web → похожие карточки → AI-проверка.
- Настройки интеграций.

Сейчас это **локальный UI-прототип** с демонстрационными данными. Реальные данные Ozon и RIV не подключены в браузере.

## Запуск

Вариант 1: просто открыть `index.html` в браузере.

Вариант 2: из каталога запустить локальный сервер:

```bash
python3 -m http.server 8080
```

После этого открыть `http://localhost:8080`.

## Следующий этап — backend

Планируем серверную часть:

- Ozon Seller API: товары, характеристики, цены, остатки, заказы, аналитика, фото.
- RIV: поиск артикула через авторизованную браузерную сессию, если API недоступен.
- Web Research: поиск по артикулу / OEM / модели.
- AI Research Engine: сверка источников и генерация карточки.
- База данных: товары, источники, OEM, применяемость, история изменений, задачи.
- Object Storage: фотографии карточек с прямыми URL.
- Audit log: кто и когда изменил название/описание/фото.

Ozon Seller API поддерживает создание и обновление товаров, обновление изображений и получение аналитических данных. Для изображений используется `POST /v1/product/pictures/import`, а для массового создания/обновления — `/v3/product/import`. См. источники в задаче проекта.
